# Data Ingestion

The first stage of the RAG pipeline: loading raw text into LangChain
`Document` objects and splitting it into chunks that can later be embedded and
stored in a vector database.

Everything lives in [code.ipynb](code.ipynb).

## Contents

| File | Purpose |
| --- | --- |
| `code.ipynb` | Walkthrough of documents, loaders and text splitters |
| `data/text_files/python_intro.txt` | Sample text: introduction to Python |
| `data/text_files/machine_learning.txt` | Sample text: machine learning basics |

The sample text files are generated by the notebook, so running it from
scratch recreates them.

## What the notebook covers

### 1. The `Document` object

A `Document` has two parts:

- `page_content`: the text that gets embedded and searched.
- `metadata`: a dict such as `source`, `page`, `author` or `date_created`.

Metadata is used to filter search results, track where an answer came from,
give the LLM context and debug the pipeline.

### 2. Loading text files

- **`TextLoader`** loads a single file into a list holding one `Document`,
  with `metadata={"source": <path>}`.
- **`DirectoryLoader`** loads every file that matches a glob pattern
  (`**/*.txt`) using a loader class (`TextLoader`), and can show progress.
  - Pros: loads many files at once, supports glob patterns and recursive
    scanning.
  - Cons: every file must be the same type, it has limited error handling per
    file, and it can use a lot of memory on large directories.

Pass `encoding="utf-8"` (or `loader_kwargs={"encoding": "utf-8"}`) to avoid
decoding errors on Windows.

### 3. Splitting text into chunks

All splitters take a `chunk_size` and a `chunk_overlap`. The overlap repeats
the end of one chunk at the start of the next, so context isn't lost at the
boundaries.

| Splitter | How it splits | Use when |
| --- | --- | --- |
| `CharacterTextSplitter` | On a single separator (e.g. `"\n"` or `" "`), measured in characters | Text has clear delimiters |
| `RecursiveCharacterTextSplitter` | Tries a list of separators in order, falling back to smaller ones | Default choice for most text |
| `TokenTextSplitter` | By tokens (via `tiktoken`) instead of characters | Staying within a model's token limit |

The notebook compares `separator=" "` with `separator="\n"` on the same text
to show how the separator changes where chunks break, and shows the overlap
on a text with no natural break points.

## Running

From the repository root, follow the setup in the [root readme](../readme.md),
then open `DataIngestion/code.ipynb` and run the cells in order. Paths are
relative (`data/text_files`), so the notebook's working directory must be
`DataIngestion/`.

> `langchain_community` raises a deprecation warning on import. The loaders
> still work, but they may move to standalone integration packages in the
> future.
